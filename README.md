### Computer Architecture

Projects focused on understanding program execution, cache and memory performance, GPU parallelism, and hardware acceleration.

| Project | Description |
| --- | --- |
| 🔍 Program Analysis | Intel Pin, dynamic instrumentation, instruction and memory profiling |
| 💾 Cache Optimization | ChampSim, LLC replacement policies (LFU, BIP, DIP, SHIP) |
| ⚡ CUDA Programming | SAXPY, Monte Carlo π, GPU memory hierarchy, speedup on NVIDIA T4 |
| 🤖 YOLO Sign Detection | CUDA training, TensorRT FP16 acceleration on Jetson, latency and FPS benchmarking |

Note: YOLO Sign Detection under Computer Architecture covers the performance; [Autonomous Racing](https://github.com/nyinyioo/autonomous-racing) covers implementation.
